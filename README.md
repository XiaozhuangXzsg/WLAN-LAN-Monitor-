# 网络流量监控

Windows 桌面程序，在同一窗口并排显示以太网和 WLAN 网卡的实时上传、下载曲线，并按软件、域名或远端 IP 汇总启动后的 IPv4 流量。主窗口的“置顶流量浮窗”选项可随时打开独立的圆角无边框浮窗；取消勾选或左键双击浮窗任意位置即可关闭。

## 运行

需要 Windows 10/11 和 .NET 8 SDK。在 PowerShell 中运行：

```powershell
dotnet run --project NetworkMonitor.csproj
```

程序清单会申请管理员权限。管理员权限用于本机原始套接字抓包；不需要安装 Npcap。以太网与 WLAN 在主窗口左右并排显示；同一类型如有多块网卡，可在各自区域的标签页切换。浮窗会汇总每种类型的所有网卡，便于实时比较。

## 仪表盘、托盘与累计流量

- 仪表盘同时显示两种网卡的实时速度、今日用量、本月累计用量。两侧图表使用相同纵轴刻度；同类型的多块网卡通过下拉框切换。
- 勾选“置顶流量浮窗”可显示四角圆角的无边框浮窗，没有标题栏和关闭按钮。按住内容区可移动浮窗，按住右下角的斜线握柄可拖动调整大小；最小尺寸为 240 × 144（100% 缩放），释放鼠标时保存尺寸和位置，下次打开或启动自动恢复。大尺寸显示完整速度、累计、比较条与额度进度条；中等尺寸省略比较条与额度进度条；最小尺寸仅保留以太网和 WLAN 的名称、上传与下载速度。放大后恢复详细内容。左键双击内容区关闭；双击缩放握柄不会关闭。主窗口最小化或收进托盘时浮窗继续显示。浮窗位于普通桌面窗口之上；Windows 安全桌面和独占全屏等系统场景不保证覆盖。
- “最小化到托盘”默认开启。点击最小化按钮或“收起到托盘”即可后台监控，双击托盘图标恢复主窗口。托盘右键菜单可切换浮窗或退出；点击主窗口关闭按钮会保存记录后收进托盘，监控继续运行；从托盘菜单选择“退出”才会结束软件。
- 网卡用量按稳定网卡 ID 保存到 `%LOCALAPPDATA%\NetworkMonitor\state.json`，每 10 秒保存；点击关闭按钮、收起到托盘、从托盘退出，以及 Windows 关机、重启或注销时立即保存，并保留上一份备份。结束会话前补采最后一次网卡计数器变化；网卡已断开或读取失败时保留已有累计。异常断电可能损失最近 10 秒记录；不会补计软件未运行期间的流量。今日用量按本机日期重置；以太网与 WLAN 的累计上传、下载流量按本机时间在每月 1 日 00:00 后首次刷新时清零，并立即保存。月初未运行时，下次启动会先清零再统计；断开或未检测到的网卡记录同样按月重置，旧备份与日志恢复后也会检查月份。主窗口与浮窗统一显示本月累计；从旧版升级时保留已有的本月用量。
- 以太网栏可设置每月限额（GiB），本月用量和剩余量在月初自动刷新。月用量按每天记录的网卡计数器变化累计；额度仅显示提醒，不会在用尽时自动断网。每月用量日志保存在 `%LOCALAPPDATA%\NetworkMonitor\usage-YYYY-MM.log`，每分钟及关闭、退出、关机、重启或注销时写入累计快照并刷新到磁盘，可在主记录和备份损坏时用于恢复。
- 以太网的月份、每月限额、本月累计上传/下载、剩余额度以及各以太网卡记录，额外追加保存到 `%LOCALAPPDATA%\NetworkMonitor\ethernet-usage.log`。该独立日志位于安装目录之外，不包含在安装包中，升级和卸载均保留。每分钟、启动、点击关闭、退出、关机、重启、注销、设置额度和跨月重置时写入并刷新到磁盘；首个新版启动时从旧版现有记录生成日志。主记录被替换为空、缺失或损坏时，软件自动检查日志恢复本月用量和额度；保留日志历史，跳过损坏的末尾记录，避免重复累加或用旧快照覆盖较新的额度。月初仍清零本月流量，恢复时不会把上月用量带回当月。移除的以太网卡本月用量仍计入总额度；未设置限额时日志中的 `RemainingBytes` 为 `null`，额度用尽时为 `0`。日志保存失败会在主窗口底部提示。Windows 发出结束会话通知时先保存记录，确认结束后才停止监控并释放浮窗；取消关机后继续监控。
- 每种网卡各显示软件和远端 IP 流量前三名；软件榜会提取对应可执行文件图标。排行统计仅保留本次运行的数据。
- 网卡卡片中的按钮可启用或禁用对应以太网/WLAN 适配器。禁用会立即中断该网卡的网络连接。
- “一键优化网络”会清除 Windows DNS 缓存，并把 TCP 自动调节恢复为 Windows 默认 Normal；不会替换校园网 DNS 或断开网卡。
- 界面采用原神幻想风格的暖白、深蓝和金色配色，卡片、切换按钮、网卡选择器和浮窗均使用圆角。主窗口字体优先选择设备已安装的原神 UI 字体；没有时使用系统黑体作为回退，不会安装或捆绑专有字体。
- “主题 ▾”菜单新增“WinUI 3 半透明”，采用浅灰白背景、蓝色强调色和 Segoe UI 字体。主窗口与浮窗同步切换，主题选择会保存并在下次启动时恢复。主窗口不透明度为 92%，浮窗为 96%；切回原有主题恢复完全不透明。该主题基于现有 WinForms 实现 WinUI 3 风格，使用 Windows [窗口不透明度](https://learn.microsoft.com/en-us/dotnet/api/system.windows.forms.form.opacity)合成实际半透明效果，文字与控件也参与透明混合；不包含原生 WinUI 3 Acrylic/Mica 背景模糊。在 Windows 11 上同时更新系统标题栏颜色和圆角偏好。浮窗文字优先使用 Microsoft YaHei UI，不随装饰字体切换；标题采用 15 像素加粗，说明为 13–14 像素，上传和下载速度均采用 15–22 像素加粗（以 100% 缩放为基准）。文字按显示器 DPI 直接绘制到整数像素位置，支持每显示器 DPI 感知，缩小窗口时优先缩紧间距以保留速度单位。
- 顶部标题区与工具栏使用窗口背景色，按钮自身按圆角裁剪，四种主题下切换、悬停和禁用时不会在圆角外出现白色矩形底板。
- 开机启动默认关闭。安装完成时可以选择开启，也可以在软件中勾选“跟随系统启动”：为当前用户创建登录后约 5 秒运行的计划任务，使用最高可用权限，后台进入托盘，并按之前设置显示浮窗；自启时不会弹出首次使用欢迎窗口。取消勾选会删除任务。不存储用户密码。开启前建议先安装到正式位置。卸载时也会移除该任务，累计记录保留。
- 自动启动使用 Windows [登录触发器](https://learn.microsoft.com/en-us/windows/win32/taskschd/starting-an-executable-when-a-user-logs-on)和[任务权限设置](https://learn.microsoft.com/en-us/windows/win32/taskschd/principal-runlevel)。

## 统计口径

- 曲线使用 Windows 网卡计数器，包含该网卡的总流量，每秒更新一次。
- 软件和域名表使用该网卡捕获的 IPv4 IP 包长度统计。它们与曲线的总数可能不同，例如 IPv6、链路层开销、丢包、分片以及无法捕获的包。
- 软件归属通过 Windows TCP/UDP 连接表匹配。连接很短、进程已结束或连接表未能及时读到时，流量归入“未归属进程”。
- 域名来自当前抓到的普通 DNS 响应；使用加密 DNS、缓存 DNS、直连 IP 时显示远端 IP。一个 IP 由多个域名共享时，域名归属可能不准确。
- HTTPS 的完整网址、路径和页面内容受加密保护，程序无法读取；表中显示的是域名或远端 IP。QUIC 和 IPv6 流量目前只计入网卡曲线，不能归属到软件或域名。
- 网卡总量支持跨重启累计；按软件与域名的明细只保留本次运行期间的数据。
